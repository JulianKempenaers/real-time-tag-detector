#first time installation:
#------------------------
#1. To download this folder, click the green 'code' button on the start page of this repository, and then 'download ZIP'
    Unzip the folder on your desktop or documents folder (not on external drive) of your Raspberry Pi. 

#2. find the 'run_installer.sh' file. double click and select 'execute in terminal'
    If there is no 'execute in terminal' button, open the file, and copy-paste the text into your terminal and hit 'enter'
    Ensure you're connected to the internet so that python packages can be installed. 

#you can also manually install the packages yourself by installing the packages listed in requirements.txt

#Using the STag-detector after installation:
#-------------------------------
#1. Choose whether you will use one or two cameras simultaneously and connect them to your Raspberry Pi before turning it on. 

#2. Run the executable .sh file (Run_Stag_Detection.sh) to open the Graphical User Interface (GUI)
Note: If the GUI does not open, open the Run_Stag_Detection.sh file and copy-paste its content into the terminal and hit 'enter'. The error message will likely imply that your camera is not detected. Restarting the raspberry pi fixes this problem. Cameras must alwasy be connected upon startup. 

#3. Refer to the README.md on github for more information about the settings to choose from (https://github.com/JulianKempenaers/real-time-tag-detector/blob/main/README.md)

#4. hit 'Esc' to close the live detector
